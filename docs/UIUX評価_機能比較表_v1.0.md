## 3. 多角的サマリー（機能比較から）

### 3-1. ピタコマが優れている（◎× または ○×）

| 観点 | 内容 |
|---|---|
| **マッチングの透明性** | 候補順位・理由バッジ（全コマ対応、指定講師等） |
| **個別指導向けコマ組み** | 定員・ブース・優先ペア・希望コマ対応数 |
| **週間オペレーション** | 生徒別/講師別/空き状況の週表示 |
| **経営分析（組み方）** | コスト率の色分け（請求SaaSとは別軸） |
| **スコープの集中** | コマ組みに機能が散らばらない |

### 3-2. ピタコマが劣る（競合◎/○ vs ピタコマ△/×）

| 観点 | 内容 | 追いかける必要 |
|---|---|---|
| **保護者・決済** | LINE/アプリ/月謝 | 低（別プロダクト想定） |
| **体験・集客** | 申込ページ、Google予約 | 低 |
| **モバイル** | スマホ最適UI | 中（UI改善で一部可能） |
| **初見のやさしさ** | オンボーディング | **高** |
| **カレンダーUI polish** | RESERVA/Comiru水準 | **高** |
| **欠席振替の保護者自助** | 保護者が空き枠選択 | 中（将来検討） |

### 3-3. 同程度（○○）

- 基本的なコマ組み・シフト回収
- 欠席振替（教室長操作として）
- 検索・絞り込み
