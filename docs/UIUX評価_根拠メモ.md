## A. コエテコマネージャー byGMO

| 項目 | 根拠 |
|---|---|
| 公式 | https://manager.coeteco.jp / https://reserve.coeteco.jp/ |
| 保護者連携・欠席振替 | 保護者専用予約サイト、欠席・振替24時間受付（PR 2025-12） |
| 請求・決済 | 月謝決済・単発決済対応（同上） |
| 体験・入会 | 体験授業申込ページ作成、Googleで予約連携 |
| コマ組み・シフト | **標準機能に講師シフト自動マッチングは非搭載**。API連携で外部連携想定（2026-04 API公開 note） |
| モバイル | 保護者向け操作を前面訴求 |

**評価メモ:** オールインワン型。ピタコマの主戦場（コマ組みロジック）とは競合軸が異なる。
