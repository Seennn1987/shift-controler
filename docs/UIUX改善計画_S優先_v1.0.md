## 3. 各施策詳細

### S1: 初回3ステップガイド

**内容:** 教室長が初めてログインしたときだけ、3ステップの案内を表示する。

| ステップ | 案内 | 関連タブ |
|---|---|---|
| 1 | 生徒を登録する | 生徒登録 |
| 2 | 講師のシフトを回収する | シフト管理 |
| 3 | カレンダーでコマを組む | カレンダー |

**仕様:**
- 「次へ」「スキップ」「始める」ボタン
- 1回表示したら `localStorage` に記録（再表示しない）
- 設定画面からの再表示は **今回は作らない**（依頼外）

**ファイル:** `src/admin/onboarding.js`, `index.html`, `admin.css`

---

### S2: 配色計画の実施（別フェーズ）

**参照:** [`配色調査・提案_v1.0.md`](配色調査・提案_v1.0.md)

**比較画面（残り作業）:** [`color-change-proposal.html`](color-change-proposal.html) — 今の画面から変える9か所のみ

**色見本:** [`color-palette-preview.html`](color-palette-preview.html)

**要点:**
- UI基盤（MF青）/ 教科色 / 状態色 の3層分離
- カレンダー黄色×チャコール廃止
- 未確定は薄青（教科色と被らない）

**次の作業:** 配色 Phase 1（variables + カレンダー土台）の計画書承認後に着手
