## 1. このガイドラインの目的

ピタコマの画面は、**教室長が毎日触る業務ツール**です。  
情報量は多いですが、**読みにくい文字・バラバラな形**は避けます。

| 目的 | 内容 |
|---|---|
| 見た目の統一 | 色・文字・ボタンの形を1か所で決める |
| 開発の迷いを減らす | AI・人間どちらも同じルールで実装する |
| 段階的改善 | いきなり全画面を直さず、トークンから順に適用 |

## 2. デザインの基本方針

### 2-1. ユーザー像

- **主ユーザー**: 教室長・事務（ITに詳しくない）
- **副ユーザー**: 講師（シフト提出・自分の予定確認）
- **画面の性質**: データが多い管理画面（カレンダー・表・リスト）

### 2-2. トーン

| 項目 | 方針 |
|---|---|
| 全体 | 白ベース・落ち着いた青・情報が読みやすい |
| 参考 | マネーフォワード クラウド（MFUI）系の信頼感 |
| 避ける | 派手な装飾、意味のない色、10px以下の本文 |

### 2-3. 3層の色（配色ルール）

| 層 | 用途 | ルール |
|---|---|---|
| **A. UI基盤** | ヘッダー・タブ・ボタン・枠線 | `--brand-*`, `--ink`, `--surface-*` |
| **B. 教科色** | 授業タグ・カレンダー予定 | 教科ごとに色相固定（既存ロジック） |
| **C. 状態色** | 未確定・欠席・休校・警告 | `--pending-*`, `--danger`, `--success` 等 |

**禁止**: 教科色をボタンやタブの背景に使う（意味が混ざる）

## 3. 文字（Typography）

### 3-1. 基本ルール

| ルール | 内容 |
|---|---|
| 基準サイズ | **14px**（`--text-base`）— 本文・入力・ボタン |
| 下限 | **11px**（`--text-xs`）— バッジ・極短ラベルのみ |
| **禁止** | 8px / 9px / 10px、0.5px刻み（11.5px 等） |
| フォント | Zen Kaku Gothic New（`--font-family`） |
| 行間 | 本文 1.5、見出し 1.35 |

### 3-2. サイズ一覧

| トークン | サイズ | 用途 |
|---|---|---|
| `--text-xs` | 11px | バッジ、学年タグ、短いステータス |
| `--text-sm` | 12px | 表の補助、タイムスタンプ、キャプション |
| `--text-md` | 13px | 説明文、フォームラベル、設定の補足 |
| `--text-base` | **14px** | **本文、入力欄、ボタン、リスト** |
| `--text-lg` | 15px | カード見出し（h2） |
| `--text-xl` | 16px | カレンダー月表示、ドロワー見出し |
| `--text-2xl` | 18px | KPI数値、ログイン画面タイトル |
| `--text-3xl` | 19px | ページタイトル（ヘッダー h1） |

### 3-3. 太さ

| トークン | 用途 |
|---|---|
| 400（normal） | 説明文、補助テキスト |
| 700（bold） | ラベル、見出し、ボタン |
| 900（black） | KPI数値、強調タブ |

### 3-4. 画面別の目安

| 画面 | 本文 | 説明 | バッジ |
|---|---|---|---|
| 設定・フォーム | 14px | 13px | 11〜12px |
| マッチング | 14px | 13px | 11px |
| 週間カレンダー（表） | 13〜14px | 12px | 11px |
| 月間カレンダー（セル内） | 12〜13px | — | 11px（12px未満にしない） |

## 5. 角丸（Radius）

| トークン | 値 | 用途 |
|---|---|---|
| `--radius-sm` | 6px | ツールチップ、小バッジ |
| `--radius-md` | 8px | 入力欄、副ボタン、リスト行 |
| `--radius-lg` | 10px | 主ボタン |
| `--radius-xl` | 12px | パネル内ブロック |
| `--radius-card` | 14px | カード |
| `--radius-pill` | 999px | ピル型バッジ・チップ |

**禁止**: 7px / 9px などスケール外の値（既存CSSは段階的に置換）

## 6. コンポーネント

### 6-1. カード

```
背景: --surface-card
枠線: 1px solid --border
角丸: --radius-card (14px)
padding: --card-padding (22px 24px)
見出し: --text-lg (15px), bold, --brand-900
説明: --text-md (13px), --ink-soft
```

### 6-2. ボタン

| 種類 | 見た目 | 高さ | 文字 |
|---|---|---|---|
| **主ボタン** | 青グラデーション、白文字 | 40px | 14px bold |
| **副ボタン（ghost）** | 白背景＋枠線 | 32〜40px | 13〜14px bold |
| **危険** | 透明背景、赤文字 | — | 12〜13px bold |

角丸: 主 `--radius-lg`、副 `--radius-md`

### 6-3. 入力欄

```
高さ: --input-height (40px)
padding: 10px 12px
角丸: --radius-md (8px)
文字: --text-base (14px)
枠線: 1px solid --border
背景: --surface-card
```

### 6-4. タブ

```
文字: 14px bold
アクティブ: --brand-600 ＋ 下線（--brand-500）
非アクティブ: --ink-soft
```

### 6-5. バッジ・チップ

```
文字: 11〜12px bold
角丸: --radius-pill または --radius-sm
padding: 2px 8px（コンパクト）
```

状態色または `--surface-muted` 背景。教科色バッジは教科色のみ。

### 6-6. ヘルプ（?）

```
? アイコン: 16px 丸、--text-sm
ツールチップ: --text-md (13px)、--radius-sm
```

## 8. 実装ルール（開発者・AI向け）

### 8-1. 必須

1. 新規CSSは **トークン（variables.css）を使う**
2. 直書きの `#ccc` 等は **禁止**（`--ink-disabled` / `--surface-card` 等を使う）
3. 角丸は **`--radius-*` のみ**（7px / 9px 等は使わない）
4. `font-size: 11.5px` 等の **0.5px刻み禁止**
5. **10px以下禁止**（Phase 2 で修正済み）

### 8-2. ファイル構成

| ファイル | 役割 |
|---|---|
| `src/shared/styles/variables.css` | トークン定義（唯一の正） |
| `src/admin/styles/admin.css` | 管理画面スタイル（トークン参照済み） |
| `src/teacher/styles/teacher.css` | 講師画面（管理画面と同トークン） |

### 8-3. 適用フェーズ
