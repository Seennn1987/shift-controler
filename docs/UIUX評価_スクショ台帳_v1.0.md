## 1. 撮影ルール

| 項目 | ルール |
|---|---|
| 解像度 | 1280px 幅以上（PCブラウザ） |
| 状態 | **通常** と **データあり** の両方がある画面は両方撮る |
| ファイル名 | `{番号}_{画面名}_{状態}.png` 例: `01_カレンダー月_通常.png` |
| 個人情報 | 実データの氏名はマスクまたは seed データ使用 |
