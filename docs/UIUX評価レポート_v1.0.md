# ピタコマ UI/UX 評価レポート v1.0

**作成日:** 2026-08-21  
**Phase:** 4（総合結論）  
**根拠:** Phase 1 競合調査 / Phase 2 7視点評価 / Phase 3 操作テスト（自動 6/6）

---

## 1. エグゼクティブサマリー

ピタコマは **「個別指導のコマ組み」に特化した中核機能で競合より優位**（7視点の「コマ組み適合」5/5）だが、**初見の分かりやすさ（2/5）と見た目の統一感（3/5）で SaaS 競合に劣る**。

操作テスト T1〜T6 は **シードデータ＋本番モジュールの自動検証で全合格**。日常業務のロジック（絞り込み解除・確定・一括仮組み・欠席振替・読み仮名検索）は実装済みで動作する。

**推奨:** 新機能追加より、**初回ガイド・配色統一・講師画面の仕上げ**を最優先する。

## 3. 強み TOP5

| # | 強み | 根拠 |
|---|---|---|
| 1 | **マッチング理由が見える** | 候補ランク・バッジ（全コマ対応、指定講師等）・優先度7項目 |
| 2 | **個別指導向けコマ組み** | 定員・ブース・優先ペア・希望コマ対応数 |
| 3 | **カレンダー＋ドロワー** | 組みながら月間・日次を確認 |
| 4 | **週間3軸表示** | 生徒別 / 講師別 / 空き状況 |
| 5 | **操作の戻しやすさ** | 絞り込み解除・確定解除・一括自動解除（T1,T3 合格） |

---

## 4. 弱み TOP5

| # | 弱み | 影響 | 優先度 |
|---|---|---|---|
| 1 | **初めて触ると全体像が掴めない** | 導入・口コミ | **S** |
| 2 | **見た目・プロ感**（講師画面デバッグ表示等） | 信頼感 | **S** |
| 3 | **ヘッダー副題と実機能のズレ** | 期待値ミスマッチ | A |
| 4 | **スマホ閲覧性** | 外出先確認 | B |
| 5 | **登録フォームが長い** | 初期セットアップ負担 | B |

## 9. 結論

ピタコマは **「なぜこの講師が選ばれたか」が分かるコマ組みツール** として競合と差別化できる。UI/UX 上の最大の課題は **機能不足ではなく、初見の案内と見た目の統一** である。

次のアクションは **S2 配色 Phase 1** を推奨する。S1/S3/S4 は 2026-08-21 実装済み。
