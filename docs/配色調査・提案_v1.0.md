**作成日**: 2026-08-16

## 1. 結論（先に要点）

ピタコマの配色は **3層に分ける** のが最適です。

| 層 | 役割 | 色の性格 |
|---|---|---|
| **A. UI基盤** | ヘッダー・タブ・ボタン・表の枠・カレンダーの土台 | 白〜温かみグレー＋**MF royalBlue**（`#3B7DE9`） |
| **B. 教科色** | 授業タグ・カレンダー予定バー・マトリクス集計 | 国・数・英・理・社で色相を固定（現行ロジックを活かす） |
| **C. 状態色** | 未確定・欠席・振替・休校・今日の日付など | 教科色と**色相が被らない**色。未確定は MF の薄青（solitude） |

**カレンダーの「黄色×チャコール」はやめる。**  
**マネーフォワード クラウド（MFUI）** と同様、白いセル＋薄いグレー罫線＋**信頼感のある青**で「今日」「選択中」を示す。

## 2. ピタコマ現状の整理

### 2-1. 変数（`src/shared/styles/variables.css`）

| 変数名 | 実際の色 | 用途 |
|---|---|---|
| `--green-900`〜`--green-500` | **チャコールグレー**（#25272b〜#7a7e87） | ヘッダー・タブ・アクティブ状態 |
| `--gold` / `--gold-soft` | ゴールドブラウン（#8a7248 / #efe9dd） | 今日の日付・未確定枠・警告系 |
| `--cream` | オフホワイト（#f7f7f6） | ページ背景 |
| `--danger` | 赤茶（#b3462c） | エラー・削除 |

※ `--green-*` という名前だが、実際は緑ではなく**グレー系**。名前と見た目がズレており、メンテナンスしにくい。

### 2-2. 教科色（`src/admin/schedule-core.js`）

色相（HSL）で固定し、小・中・高で濃淡を変える方式。**良い設計**。

| 教科 | 色相 (H) | イメージ |
|---|---|---|
| 国語 | 352 | 赤〜ローズ |
| 算数・数学 | 208 | 青 |
| 英語 | 265 | 紫 |
| 理科 | 138 | 緑 |
| 社会 | 32 | 橙 |

### 2-3. 問題になっている箇所

| 箇所 | 現状 | 問題 |
|---|---|---|
| カレンダー「今日」 | ゴールド丸（`--gold`） | 未確定の黄色と近く、目が疲れる |
| カレンダー「選択中セル」 | チャコール塗り（`--green-700`） | セル内の教科色タグと競合し、暗く重い |
| 未確定（pending） | `#fff3cd` 黄＋ `#856404` 茶 | **社会（橙）・国語（赤）と混同**しやすい |
| 曜日ヘッダー（収支） | `#e9e2c8` 黄みグレー | カレンダー全体が「黄色っぽい」印象 |
| UI全体 | チャコール＋ゴールド＋黄 | 2020年代のSaaSと比べて**重く古い**印象 |

## 3. 競合・参考サービスの配色調査

> 公開情報・デザインシステム文献・公式サイトから整理。管理画面のスクショは非公開のサービスは「公式訴求＋業界慣習」で補完。

### 3-1. 国内：塾・スクール管理SaaS

| サービス | UIの基調 | カレンダー・色分け | 特徴 |
|---|---|---|---|
| **コエテコマネージャー byGMO** | 白背景・シンプルUI（公式訴求） | コースごとの色分け表示（機能説明より） | ITに不慣れでも使える**機能絞り込み型**。派手な装飾より可読性 |
| **wagaco** | 白〜ライトグレー・フラット（公式訴求「シンプル」） | 教科色の固定パレットは**なし**（タグ・検索で整理） | 「誰でも簡単に」が最優先。色より情報密度を下げる |
| **RESERVA school** | 白カード・薄い罫線（2025年カレンダーリニューアル） | 予約ブロック＝帯表示、ホバーで詳細 | **TimeTree / Googleカレンダー**に近い「白＋細線」 |
| **Smart Hello** | 白基調・青系アクcent（業界記事・LP傾向） | 予約状況を一覧・カレンダーで表示 | 保護者アプリ連携型。管理画面は控えめ |
| **Square予約** | Square共通：**白＋黒文字＋Squareブルー** | Googleカレンダー同期 | 決済SaaS系の**極限シンプル** |

**国内共通点**
- 管理画面は **白 or ごく薄いグレー** が主流
- ブランド色は **1色**（青・緑・橙など）に絞る
- 教科・コース色は **カレンダー内のタグだけ** に使い、UIの骨格には使わない

### 3-2. 海外：スケジュール・業務SaaS（デザインシステム公開）

| サービス | 背景 | 文字 | プライマリ（操作色） | カレンダー |
|---|---|---|---|---|
| **Calendly** | `#ffffff` / `#f8f9fb` | ネイビー `#0b3558` | ブルー `#006bff` | 白セル・細い青灰ボーダー・ノイズ最小 |
| **Notion** | ペーパーホワイト `#f6f5f4` | `#31302e` | シグナルブルー `#0075de` | コンテンツ色はユーザー設定、UIは中立 |
| **Linear** | ライト：ほぼ白 / ダーク：#101012 | `#EEEFFC` | パープル `#5E6AD2` | ミニマル。色はステータスにのみ |
| **SavvyCal** | クリーム `#fcfbf8` | `#171512` | ライム `#b4ff78`（限定使用） | ヒーローだけ濃色、本体は紙色 |

**海外共通点（2025–2026 SaaS UIトレンド）**
- **Strategic Minimalism**：画面の70%以上を無彩色
- テキストは純黒 `#000` より **スレート／ネイビー**
- 影は `rgba(15, 23, 42, 0.08)` のような**冷たいグレー**
- カレンダーは **Google Calendar / TimeTree 系**（白セル・細罫線）がデファクト

### 3-3. Google Calendar（教科色の「業界標準」に近い）

イベント色パレット（Material系・よく引用される値）:

| 名前 | 背景例 | 教科との対応イメージ |
|---|---|---|
| Tomato / Flamingo | `#e67c73` | 国語 |
| Tangerine / Pumpkin | `#f4511e` / `#ef6c00` | 社会 |
| Banana / Citron | `#f6bf26` / `#e4c441` | ※警告に使うと教科と混同 |
| Sage / Basil | `#33b679` / `#0b8043` | 理科 |
| Peacock / Cobalt | `#039be5` / `#4285f4` | 数学 |
| Grape / Wisteria | `#8e24aa` / `#b39ddb` | 英語 |
| Graphite / Birch | `#616161` / `#a79b8e` | 休校・非稼働 |

→ **ピタコマの教科色相（国=赤、数=青、英=紫、理=緑、社=橙）は Google Calendar とも整合**しており、この方向性は維持してよい。

## 4. 競合調査から得た設計原則（5つ）

1. **UIの骨格は無彩色** — 教科色をヘッダー・タブ・表見出しに使わない  
2. **ブランド色は1系統** — ボタン・リンク・「今日」「選択中」にだけ使う  
3. **教科色はタグ／バーだけ** — セル背景は白のまま  
4. **状態色は教科色相と被らない** — 黄（未確定）は廃止方向  
5. **カレンダーは TimeTree 準拠を維持** — 罫線のみ区切り、丸角ボックス化しない（現行方針と一致）

## 4.5 参考：マネーフォワード クラウド（MFUI）の配色

ピタコマのUI基盤は **MFUI（Money Forward UI）** の考え方を参考にする。バックオフィスSaaSとして「信頼・安定・長時間見ても疲れない」を優先。

| MFUI名 | HEX | ピタコマでの用途 |
|---|---|---|
| royalBlue | `#3B7DE9` | プライマリボタン・アクティブタブ・今日の日付 |
| cobalt | `#0054AC` | ホバー・未確定の文字色 |
| solitude | `#ECF2FD` | 未確定タグ背景 |
| darkenAliceBlue | `#EDF5FE` | 選択行・選択中セル背景 |
| cloudGrey | `#EFF1F4` | 表ヘッダー・フィルタバー |
| whiteSmoke | `#F7F7F7` | ページ背景 |
| linkWater | `#D4D8DD` | 罫線 |
| nightRider | `#333333` | 本文（真っ黒にしない） |
| stormGrey | `#787E8D` | 補助テキスト |
| vulcan | `#32373F` | ヘッダー背景 |
| rhino | `#424954` | タブ非選択 |
| apple | `#65AB51` | 成功・確定 |
| venetianRed | `#D0021B` | エラー |
| cornSilk / mcKenzie | `#FCF8E3` / `#8A6D3B` | 警告（限定的） |

**MFUIの特徴（ピタコマに取り入れる点）**
- プライマリボタンは **royalBlue → cobalt の縦グラデーション**（押して安心感）
- テキストは `#000` ではなく **nightRider `#333333`**（温かみ）
- 選択・未確定は **薄い青 tint**（黄ではない）
- 角丸 **4px前後**（MF Cloud は控えめな丸み）

**取り入れない点**
- MFの警告黄（cornSilk）はカレンダー未確定には使わない（教科・状態と混同しやすい）
- マーケティングLPの黄色アクセントは管理画面には不要

## 5. ピタコマ配色提案

### 5-1. 推奨案：**「MFクラウド系ブルー」**（v1.1 — インディゴ案から改訂）

**改訂理由**: `#6366F1`（インディゴ／青紫）は「SaaSっぽいが安っぽい」印象。MF の `#3B7DE9` は**ビジネス向けの落ち着いた青**で、日本の教室長向けツールに馴染む。

#### A. UI基盤トークン（新 `--*` 案）

| トークン | 値 | MFUI参考 | 用途 |
|---|---|---|---|
| `--surface-page` | `#F7F7F7` | whiteSmoke | ページ背景 |
| `--surface-card` | `#FFFFFF` | white | カード・カレンダーセル |
| `--surface-muted` | `#EFF1F4` | cloudGrey | フィルタバー・表ヘッダー |
| `--ink` | `#333333` | nightRider | 本文 |
| `--ink-soft` | `#787E8D` | stormGrey | 補助テキスト |
| `--border` | `#D4D8DD` | linkWater | 罫線 |
| `--brand-900` | `#32373F` | vulcan | ヘッダー背景 |
| `--brand-700` | `#424954` | rhino | タブ非選択 |
| `--brand-500` | `#3B7DE9` | royalBlue | **プライマリ** |
| `--brand-600` | `#0054AC` | cobalt | ホバー・未確定文字 |
| `--brand-100` | `#EDF5FE` | darkenAliceBlue | 選択行・ホバー |

プライマリボタンは `linear-gradient(180deg, #3B7DE9, #0054AC)` を推奨（MF Cloud 準拠）。

#### B. 教科色（現行HSLを維持）

変更なし。数学タグは **淡い空色（パステル）**、UIボタンは **濃い royalBlue（ソリッド）** で役割を分ける。

| 教科 | 背景 HEX目安（中学） | 文字色 |
|---|---|---|
| 国語 | `#F9D4DC` | `#7A1E34` |
| 数学 | `#CFE8FA` | `#0C4A6E` |
| 英語 | `#E8DEFF` | `#4C1D95` |
| 理科 | `#D7F0DE` | `#14532D` |
| 社会 | `#FCE7CF` | `#7C2D12` |

#### C. 状態色

| 状態 | 背景 | 枠・文字 | 備考 |
|---|---|---|---|
| **未確定** | `#ECF2FD` | 破線 `#3B7DE9` / 文字 `#0054AC` | MF solitude。黄廃止 |
| **欠席** | `#F7F7F7` | 文字 `#AAAAAA`＋打消し線 | |
| **振替** | 教科色のまま | 破線 `#333333` | |
| **休校・定休** | `#EFF1F4` | 文字 `#AAAAAA` | |
| **祝日** | `#FFEEEB` | 日付 `#D0021B` | MF mistyRose |
| **今日** | — | 丸 `#3B7DE9`＋白文字 | ゴールド廃止 |
| **選択中セル** | `#EDF5FE` | 外枠 `2px #3B7DE9` | チャコール塗り廃止 |
| **成功・確定** | `#EEF6EB` | 文字 `#65AB51` | MF apple |
| **警告** | `#FCF8E3` | 文字 `#8A6D3B` | MF cornSilk（カレンダー外のみ） |
| **エラー** | `#FFEEEB` | 文字 `#D0021B` | MF venetianRed |

#### D. 科目色 × UI色の役割分担

| 用途 | 色 | 数学タグとの違い |
|---|---|---|
| ボタン・タブ | `#3B7DE9` ソリッド（濃い） | タグは `#CFE8FA` パステル（薄い） |
| 未確定 | `#ECF2FD` 背景＋青破線 | 社会（橙）・国語（赤）と被らない |
| 成功 | `#65AB51` | 理科（淡緑タグ）より彩度・用途が異なる |
